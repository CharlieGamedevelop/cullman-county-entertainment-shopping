# Cullman County Entertainment & Shopping

Live: https://charliegamedevelop.github.io/cullman-county-entertainment-shopping/

A free, independent community guide to Cullman and every town in Cullman County, Alabama: the "Cullman County Today" news front page, the Game Center, events with add to calendar files, places to eat and shop, and the countywide community network.

## How it is built
- Pages are generated by the build script (kept with the project working files) from the JSON data files. Do not hand edit the HTML.
- `app.js` renders every list, the site search, filters, the Menu, the Day/Night toggle and the Game Center (which reloads `scores.json` every minute).
- `style.css` holds the light blue, black and white theme. Colors live in the `:root` and `html[data-theme=dark]` variables at the top.
- Story pages are `story-<id>.html`, built from `news.json`. Calendar files are in `ics/`.

## Data files
| File | What it holds |
| --- | --- |
| `news.json` | Original news stories, each with dated sources |
| `scores.json` | Game Center teams (initials and colors only) and games |
| `events.json` | Cullman County events; past events hide automatically |
| `businesses.json`, `eats.json`, `shops.json` | Verified local businesses |
| `directory.json` | City, county, towns, courts, public safety, schools, libraries |
| `resources.json` | Help programs, each marked `level`: Local, State or Federal |
| `nonprofits.json`, `fun.json`, `wallace.json` | Nonprofits, things to do, Wallace State services |

Keep copy plain, friendly and free of dashes. Only add facts you can verify, and log the source.

## Facebook Page
The `FB` setting in the build script and in `app.js` is empty on purpose. While it is empty, no Facebook link appears anywhere. Paste the Page URL in both places and rebuild when the Page is ready.

## Content rules
No logos, mascots or outside photos. News is written in our own words with links to every source. Business owners can ask for changes at shoplocalhanceville@gmail.com.

## Countywide community network
This site is designed to become the county mega hub for a 15-site municipal network. Each town keeps its own local website and identity, while the county hub aggregates the most relevant countywide stories and links back to each original source.

### Recommended network layout
- Each municipality gets a dedicated site, such as `hanceville-al-portal` or `cullman-city-portal`.
- Every municipal site publishes a public story feed in a standard format.
- The county hub reads each feed, validates it, deduplicates it, and ranks the newest and most relevant stories.
- County hub stories should always attribute the original municipality and provide a direct link back to the source story.

### Required feed format
The municipal feed should include:
- `title`
- `url`
- `municipality`
- `publishedAt`
- `summary`
- `category`
- `image` (optional)
- `sourceName` or `sourceUrl`
- `status` (published, draft, archived)

A working example is stored in `community-feed-template.json`.

### Network note
This is a static GitHub Pages architecture. Real-time updates still require a rebuild and redeploy from a GitHub Action or similar automation. For public safety or government notices, an editorial approval step is strongly recommended before publishing countywide highlights.
